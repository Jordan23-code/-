# AIサイト自動生成エンジン(MVP / フェーズ①)

顧客のヒアリング内容(業種・事業内容・希望トーン等)を入力すると、AIが1ページ構成のサイト文章・配色を自動生成し、その場でプレビュー表示 + 納品用の単一HTMLファイルとしてダウンロードできるMVPです。

「全自動でWEB作成 + 案件獲得」構想の中の、**①WEB作成の自動化**部分にあたります。②③④(自社LP+広告 / クラウドソーシング応募 / SNS営業)は別途、規約リスクを踏まえて段階的に追加していく想定です。

## セットアップ

このプロジェクトは Cowork のサンドボックス環境(ネットワーク制限あり)で作成したため、`npm install` はまだ実行できていません。**このフォルダで、あなたのPCの通常のターミナル(GitHub Desktopではなくコマンドプロンプト/PowerShell/VS Codeのターミナルなど)から**以下を実行してください。

```bash
cd "C:\Users\User\Documents\GitHub\-"
npm install
copy .env.example .env.local
```

`.env.local` を開き、`ANTHROPIC_API_KEY` に実際のAPIキー(https://console.anthropic.com/ で発行)を入力してください。

```bash
npm run dev
```

`http://localhost:3000` を開くとフォームが表示されます。

## もし `npm install` や `npm run dev` でエラーが出たら

エラーメッセージをそのまま貼ってもらえれば、こちらで修正します(このサンドボックスはネットワーク制限があり `next build` での動作確認ができていないため、初回セットアップでの微調整が必要になる可能性があります)。

## 構成

```
app/
  page.tsx              フォーム + プレビュー画面(クライアント)
  api/generate/route.ts AI生成API(Anthropic Messages APIを呼び出し)
  layout.tsx / globals.css
lib/
  types.ts                 型定義
  generateStaticHtml.ts    納品用HTMLを組み立てる関数
```
